#vim

> [!info] Vim command line supports tab autocompletion

## Navigation
```
h - Move cursor left
j - Move cursor down
k - Move cursor up
l - Move cursor right
-----------------------
g - Move cursor to bottom
gg - M/ove cursor to top
0 - Move cursor to begining of line
$ - Move cursor to end of line
```

## Editing
```
v - Enter edit mode
escape - Exit edit mode

u - Undo
ctrl+r - Redo
-----------------------
x - Delete character at cursor
yy - Yank/Copy
p - Paste
```

## Saving and Quitting
```
:W - Save to file
:WQ - Write file and quit
:Q! - Quit without saving
```

## Scripting
```
% - Go to matching brackets

```
