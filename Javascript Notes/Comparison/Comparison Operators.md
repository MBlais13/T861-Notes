#comparison-operators

```javascript
true >= false // Greater than or equal to
// true
true <= true // Less than or equal to
// true
true == false // Equal to
// false
true != true // Not equal to
// false
```

```js
null == undefined
// true
null == 0
// false
```
`null == 0` is `false` since `0` is a number,
`null` and `undefined` are the same thing, therefore it is true.
